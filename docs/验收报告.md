## 四、诚实限制（未验证项）

1. **三家网盘真实链路未联调**：本机无账号，登录/秒传/真实上传下载/分享需按
   [待验证清单.md](待验证清单.md) 回归；协议实现依据 Python 源码 + 研究规格。
2. **Windows 实机未跑**：本机是 Linux；Windows 编译/打包由 CI 覆盖，
   但未在 Win10 桌面双击验证（egui 官方支持 Win10/11，风险低）。
3. **传输任务重启恢复**：任务列表/状态会恢复，但跨进程恢复自动续跑需要驱动重绑定
   （当前需用户重新创建该任务）；已在 PORTING/README 中注明。
4. 目录下载、上传断点续传、回收站/云添加入口：未做（超出本次「网盘管理」核心范围，
   或协议需要分片会话支持）。
5. 分享创建已接协议，但分享列表/取消的界面入口未暴露（P2）。

## 七、结论

- **可运行**：Linux 下 GUI 启动、7 个页面 + 10 类对话框全部渲染正常（无头截图实证）。
- **可测试**：196 个自动化测试全绿，覆盖协议纯逻辑、下载器、传输引擎、敏感词守卫、回收站/云任务/记录/分享解析映射。
- **可跨平台**：单二进制、无系统 GUI 框架依赖；构建脚本 + CI 覆盖 Win/Linux。
- **可维护**：分层清晰（core/net/drive/adapters/transfer/gui），新增网盘只需实现 `Drive` trait。
- **协议可信度**：光鸭/夸克已完成真实账号端到端回归（含 sha256 校验）；
  百度读操作已验证、写操作受官方扫码会话权限限制（需 Cookie 登录绕行，已文档化）。
