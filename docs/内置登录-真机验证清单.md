# 内置登录窗口 · 真机验证清单

> 目标：确认「绿色版解压即用、无需另装浏览器」在真账号上成立。
> 工程侧链路已用注入测试验证（`./scripts/verify-login-import.sh`，
> 覆盖：内置窗口启动 → CDP 读 Cookie → 应用收到会话并开始导入）。
> 本清单只剩**真账号服务端校验**这一步。

## 0. 准备

```bash
cd 网盘管理_V10
./scripts/verify-login-kernel.sh     # 内核可用（版本 + CDP 握手）
./scripts/verify-login-import.sh     # 链路通（注入测试 Cookie，不需要真账号）
./出/网盘管理-linux-x64/网盘管理
```

确认环境里**没有** Chrome/Edge/Chromium 也能完成下面步骤（这才是本方案的意义）。

## 1. 百度（短信登录 → 写权限）

1. 「登录」→ 选择百度实例 → 切到「🌐 内置浏览器」→「打开内置登录窗口」；
2. 窗口里点【短信登录】→ 填手机号 + 验证码（或扫码/密码）；
3. 登录成功后**不要手动关窗口**，等主程序自动导入（日志出现
   `内置登录窗口：取到 baidu 的会话，正在导入`）；
4. 回主程序确认：
   - [ ] 账号状态变为已登录、目录能刷新；
   - [ ] 新建文件夹成功（写操作恢复，不再出现 `errno:-6 / 会话只读`）；
   - [ ] 日志出现 `会话已通过 /api/loginStatus 刷新：… write_ok=true`。

## 2. 夸克（短信登录）

1. 同上打开内置登录窗口 → 完成登录；
2. 确认：
   - [ ] `内置登录窗口：取到 quark 的会话，正在导入`；
   - [ ] 目录列表正常、上传/新建成功。

## 3. 光鸭（短信/令牌，不需要浏览器）

1. 「登录」→ 光鸭 → 短信登录（手机号 + 验证码）或令牌登录；
2. 确认：
   - [ ] 登录成功、目录正常；
   - [ ] 全程没有打开任何浏览器窗口。

## 4. 收尾行为

- [ ] 登录中关闭主程序：内置登录窗口应随之关闭（`on_exit → shutdown_active`）；
- [ ] 强杀主程序后重开：日志出现 `已清理上次异常退出残留的内置登录配置：N 个`（`sweep_stale`）；
- [ ] 取消登录：窗口关闭、`数据/浏览器登录/` 不残留目录、无 chrome 进程。

## 异常排查

| 现象 | 先查 |
|---|---|
| 窗口打不开 / 闪退 | `./scripts/verify-login-kernel.sh` 失败信息；`ldd 登录内核/chrome \| grep "not found"` |
| 窗口开了但登录后不导入 | 日志里有没有 `当前页面 https://…`；`curl http://127.0.0.1:<端口>/json/version`（日志会打印端口） |
| 导入后仍只读 | 账号空间超限 / 服务端风控；换扫码或稍后重试 |
