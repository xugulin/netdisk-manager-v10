# 内置 Chromium 登录 · 交付说明（2026-10-28）

## 目标
登录窗口**只使用随包内置的精简 Chromium**（`登录内核/`），删除系统 WebView、L1 JS 宿主、
外部浏览器探测等冗余登录代码；绿色版解压后**无需另装任何浏览器**即可完成百度/夸克/光鸭登录
（含短信登录），并自动导入会话。

## 一、架构（最终形态）

```
用户点「🌐 内置浏览器」
  └─ browser_login::run()
       ├─ 找 <程序目录>/登录内核/chrome（只认内置，不探测系统浏览器）
       ├─ 启动 Chromium：独立临时配置 + --remote-debugging-port + 1024x768
       ├─ CDP：/json/list → WS → Network.getAllCookies
       ├─ 必需 Cookie 过滤/去重（百度 BDUSS+STOKEN；夸克 __kps+__uid）
       └─ 事件 Cookies → app 调适配器 login_cookie 导入并持久化
收尾：on_exit → shutdown_active()；崩溃/强杀 → 下次启动 sweep_stale()
```

## 二、代码增删

| 动作 | 内容 |
|---|---|
| 删 | `crates/wp-weblogin`（GTK/WebKitGTK 系统 WebView）、`js-host`（QuickJS 宿主）、`js_probe`、`js-host-parity.sh`、系统浏览器路径探测表、`webview-login`/`js-host` feature 与相关 UI 文案 |
| 改 | `browser_login.rs`：只认内置内核 + CDP 读取修复（头+Content-Length）+ 生命周期清理 + 启动清扫 + 验收注入钩子（acceptance 专用） |
| 增 | `fetch-login-chromium.sh/.ps1`（下载并精简 Chromium）、`verify-login-kernel.sh`、`verify-login-import.sh`、`login-kernel.rev`（1728157 固定版本）、真机验证清单、两个纯 HTTP 探针（夸克/光鸭） |
