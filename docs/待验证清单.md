## 7. 百度「会话只读 / errno:-6」诊断（2026-10-19）

**结论**：写接口需要「BDUSS + 最新 STOKEN 换出的 bdstoken」；当浏览器重新登录导致
STOKEN 轮换、或导入的 Cookie 里 STOKEN 不是最新时，读接口（list/getinfo/loginStatus）
仍正常，写接口（create/filemanager/upload/share）**一律 errno:-6**。不是客户端协议错误。

| 验证项 | 结果 |
|---|---|
| 只读会话（uk 274160833，数据目录现用凭证） | `gettemplatevariable` -6；`/api/create` -6；账号 JSON `write_ok=false`；GUI 显示「已登录（只读）」+ 橙色提示 |
| 有效 Cookie（uk 455281002，V2 旧会话导入 `wp-cli login-cookie`） | `gettemplatevariable` errno=0、`write_ok=true`；`mkdir /V10CookieGUI验证` status=0；删除 ok=1 |
| GUI「登录 → Cookie」端到端 | 自动输入 Cookie → 「导入并校验」→ 日志「已导入 Cookie：BDUSS、BDUSS_BFESS、STOKEN、BAIDUID」「写会话校验通过」「登录成功：x894597841」，凭证落盘；随后 CLI 用同一凭证 mkdir 成功 |
| 修复 | 新增 `Session.write_ok`：`gettemplatevariable` 成功/写请求成功置 true；loginStatus 兜底不再覆盖已有 bdstoken，只读状态在 GUI 显示为「已登录（只读）」并给出重新登录指引；errno:-6 文案改为可执行步骤 |

**用户处理步骤**（若你的百度实例显示「已登录（只读）」）：
1. 顶栏右键该实例 →「登录 / 更换账号」→ 重新扫码；或
2. 浏览器重新登录 pan.baidu.com → F12 复制最新 `BDUSS=…; STOKEN=…`（建议带 `BDUSS_BFESS`）
   →「登录 → Cookie」导入并校验；
3. 若空间已超限，先清理/扩容。

## 9. 「进度 0% 但已完成」= 空目录任务 —— 真机定位与修复（2026-10-19）

现象：传输页出现多个任务「进度 0%、状态已完成」，用户认为传输失败/丢数据。
真机从 `任务.json` 定位到这些任务 `total=0 && done=0 && state=done`，备注为
`跨盘目录复制：0 个文件 / 0 个子目录`、`目录下载：0 个文件 / 0 个子目录`；
对应源是 **百度网盘（2）账号的 `/IDA95`，该目录本身为空**（`ls` 返回 0 条目）。
即：不是传输失败，而是「空目录」任务此前用 `done/total` 算进度（0/0=0%）+ 无明确提示。

修复与验证：

| 修复 | 验证 |
|---|---|
| `TransferTask::progress()`：Done 恒返回 100%；`progress_text()` 对 total=0 的 Done 显示 `100%（空目录）` / `100%（0 B）` | wp-core 新增 4 项单测；GUI 传输页旧任务重开后从 0% 变 100% 绿色条（截图） |
