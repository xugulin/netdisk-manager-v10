# 待真机验证清单

> 本机没有三家网盘的真实账号。以下项目已按 Python 源码逐行移植并通过纯逻辑单测，
> 但**必须用真实账号回归**后才能宣称协议可用。验证时请保留 `数据/日志/`（或界面「日志」页导出）。
>
> 通用记录格式：`条目 | 账号 | 结果(✅/❌) | 失败日志片段 | 复现步骤`

## 0. 环境

- [ ] `网盘管理 --demo` 能启动，中文正常（无豆腐块），传输页能跑演示上传/下载
- [ ] `网盘管理 --drive local` 能浏览主目录、上传/下载文件（本机驱动等价复制）
- [ ] Windows 10/11 双击 exe 不弹控制台；Linux 下 xdg-open 能打开下载目录
- [ ] 设置页修改主题/并发/下载目录 → 保存 → 重启后仍生效
- [ ] 断网后操作：界面不卡死，日志有网络错误，恢复网络可重试

## 1. 百度网盘

登录
- [ ] 扫码登录：二维码正常显示（服务端下发 PNG）→ 手机百度网盘 App 扫码 → 手机确认 → 自动登录
- [ ] 二维码过期后能点击「重新获取」
- [ ] Cookie 登录：`BDUSS=...; STOKEN=...` 导入成功并校验
- [ ] 退出登录只清本地凭证（不吊销云端）
- [ ] 会话过期（换设备/长时间后）→ 状态变「未登录」，重新扫码可恢复

文件
- [ ] 列根目录 / 多级目录，中文/emoji/特殊字符文件名显示正确
- [ ] 新建文件夹（含多级 `a/b/c`）
- [ ] 重命名、删除（文件+目录）、移动、复制
- [ ] 搜索

上传
- [ ] 小文件（<1MB）上传，云端列表可见
- [ ] 大文件（>100MB）分片上传，进度到 100%，云端大小一致
- [ ] 秒传（重复文件）命中，速度明显更快
- [ ] 文件名含中文/空格/emoji
- [ ] 上传中「暂停」→「继续」；上传中「取消」
- [ ] 敏感词守卫：命中「拦截」时任务失败且提示；命中「自动改名」时云端出现拼音名

下载
- [ ] 小文件下载，内容 sha256 与云端一致
- [ ] 大文件（>100MB）多段下载，可续传（中途暂停/断网后继续）
- [ ] 含中文/特殊字符文件名落盘正确

分享
- [ ] 创建分享 → 得到链接+提取码 → 浏览器打开可访问
- [ ] 取消分享（如界面入口已接）

## 2. 夸克网盘

登录
- [ ] 扫码登录（本地生成二维码）→ 手机夸克 App 扫码确认 → 自动登录
- [ ] Cookie 手动登录（`__kps/__uid` 等）校验成功
- [ ] 退出登录 / 会话过期重登

文件
- [ ] 列目录（根 + 多级），fid 路径解析正确（同名目录/深层目录）
- [ ] 新建、重命名、删除、移动、复制、搜索
- [ ] 刚上传的文件 1–3 秒内列表可见性（适配器是否有重试）

上传
- [ ] 小文件上传 + MD5 秒传
- [ ] 大文件分片上传（并发/重试），云端大小一致
- [ ] 上传中暂停/继续/取消

下载
- [ ] 直链下载（请求头必须项是否正确）
- [ ] 大文件多段续传
- [ ] 断网重试后能继续（不产生 0 字节文件）

分享
- [ ] 创建分享、链接可用

## 3. 光鸭云盘

登录

- [ ] 短信登录（手机号含国家码；官方可能限流）
- [ ] 令牌登录（access/refresh token）

文件
- [ ] 列目录（根 + 多级）
- [ ] 新建、重命名、删除、移动、复制、搜索
- [ ] 云添加（离线下载/转存）如界面有入口

上传（重点：OSS）

- [ ] 大文件分片上传（OSS MultipartUpload 路径：初始化→分片→完成）

- [ ] 上传进度 100% 且云端大小一致
- [ ] 透明路径（OSS 直传）与业务接口最终落库一致

下载
- [ ] 直链下载 + 大文件续传

## 4. 传输引擎（三家通用）

- [ ] 批量上传 20+ 小文件：并发不崩、无同名覆盖、全部完成
- [ ] 批量下载 20+ 文件：同上
- [ ] 跨盘传输：夸克 → 光鸭、百度 → 夸克（小文件 10 个 + 大文件 1 个），核对目标端**实际落地**（大小 + 数量）
- [ ] 任务中途退出程序 → 重启后任务列表恢复（进行中 → 暂停/排队）
- [ ] 磁盘满 / 无权限目录：任务失败且错误可读，不崩溃
- [ ] 限速设置生效（可选）

## 5. 失败时请提供

1. 网盘类型 + 账号脱敏信息 + 操作路径；
2. 「日志」页导出的日志文件（或 `数据/日志/运行-*.log`）；
3. 若为协议错误：浏览器开发者工具里对应请求的 URL / 请求头 / 响应体（脱敏 Cookie/token）；
4. 应用版本（关于页）与操作系统版本。
